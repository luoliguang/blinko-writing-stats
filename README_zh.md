# Writing Stats — Blinko 插件

一个为 [Blinko](https://github.com/blinko-space/blinko) 设计的写作统计插件，追踪你的写作连续天数、每周规律、月度趋势和标签使用情况。

## 功能

- **连续天数** — 显示当前连续写作天数和历史最长连续记录
- **热力图** — GitHub 风格的过去 23 周贡献热力图，点击任意格子可预览当天的笔记
- **每周规律** — 极坐标放射图，直观展示你在一周中哪几天最活跃
- **标签云** — 按使用频率比例展示你最常用的标签，带颜色编码
- **月度趋势** — 折线图追踪过去 6 个月的字数输出变化
- **统计卡片** — 笔记总数、总字数、活跃天数、最长连续一览无余

## 安装

通过 Blinko 插件市场安装，或手动安装：

1. 下载最新版本的 zip 文件
2. 打开 Blinko → 设置 → 插件 → 从文件安装

## 使用方法

点击 Blinko 工具栏中的 **✍️ Writing Stats** 按钮打开统计对话框。

- 点击热力图格子，查看该天写过的笔记
- 点击笔记行，展开完整预览内容
- 点击 **打开笔记** 直接跳转到对应笔记

## 开发

```bash
yarn install
yarn dev        # 启动开发服务器（热重载）
yarn vite build # 生产环境构建
```
