# ✍️ Writing Stats — Blinko 插件

> 追踪你的写作习惯，可视化你的坚持，发现笔记旅程中的规律。

一个为 [Blinko](https://github.com/blinko-space/blinko) 设计的统计插件，将你的写作历史转化为精美的交互式图表——连续天数、贡献热力图、每周极坐标图、标签云和月度趋势，全部集成在一个对话框中。

---

## 功能介绍

### 🔥 连续天数
随时掌握你的写作势头。主卡片显示**当前连续天数**和**历史最长连续**，并用圆点轨迹可视化活跃记录。未写作时为灰色，保持连续时切换为生动的靛紫渐变。

### 📅 贡献热力图
GitHub 风格的 **23 周热力图**，展示每一天的写作情况。格子颜色深浅反映笔记篇数。点击任意格子可查看当天的笔记列表——每条笔记支持展开阅读完整内容，并可点击**打开笔记**直接在 Blinko 中跳转到对应笔记。

### 🌐 每周规律（极坐标放射图）
独特的**极坐标放射图**将一周七天映射为从圆心向外辐射的条形。条越长，当天越活跃。最活跃的那天带有靛紫光晕。悬停任意条时，中心圆显示对应的笔记数量。

### 🏷️ 标签云
按使用频率**比例展示**你最常用的标签——频率越高，字体和内边距越大。每个标签的颜色由标签名哈希决定，固定且唯一，保持视觉一致性。

### 📈 月度趋势
使用 **Catmull-Rom 贝塞尔曲线**绘制的平滑折线图，追踪过去 6 个月的字数变化。渐变填充、悬停提示和动画圆点，让你轻松发现最高产的时段。

### 🃏 统计卡片
四张带**数字滚动动画**的数据卡片：

| 卡片 | 内容 |
|------|------|
| 笔记数 | 过去一年的笔记总篇数 |
| 总字数 | 累计写作字符数 |
| 活跃天 | 至少写过一篇的天数 |
| 最长连续 | 历史最长连续写作天数 |

## 安装

直接从 **Blinko 插件市场**安装，或手动安装：

1. 从[最新 Release](https://github.com/luoliguang/blinko-writing-stats/releases/latest) 下载 `release.zip`
2. 打开 Blinko → **设置 → 插件 → 从文件安装**
3. 选择下载的 zip 文件

---

## 使用方法

点击 Blinko 工具栏中的 **✍️ Writing Stats** 按钮打开统计对话框。

**热力图标签页**
- 悬停格子，查看日期和笔记数
- 点击格子，在热力图下方展开**当日笔记面板**
- 点击笔记行，展开完整预览内容
- 点击**打开笔记**，直接跳转到 Blinko 中的对应笔记

**每周标签页** — 悬停任意条形，中心圆实时更新当天数量

**标签标签页** — 悬停标签 pill，触发浮起效果

**趋势标签页** — 悬停月份数据点，显示精确字数提示

**语言切换** — 点击连续天数卡片右上角的 `中文 / EN` 切换语言

## 技术栈

基于 [Preact](https://preactjs.com/) + [Vite](https://vitejs.dev/) 构建，调用 [Blinko 插件 API](https://docs.blinko.space/zh/plugins/plugin-api)。

- 所有图表均为手写 SVG，无第三方图表库依赖
- 平滑曲线通过 Catmull-Rom → 三次贝塞尔转换实现
- 颜色适配 Blinko 的深色/浅色主题 CSS 变量
- 时区安全：所有日期比较使用本地日历日期，避免跨时区偏差

## 本地开发

```bash
yarn install
yarn dev              # 启动开发服务器，热重载，端口 :8080
yarn vite build       # 生产构建 → release/index.js
bun release:publish   # 构建 + 创建 GitHub Release + 提交到插件市场
```
